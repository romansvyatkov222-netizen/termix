# Termix

SSH-терминал и SFTP в одном окне. Десктопное приложение для Windows 10/11 x64.

## Возможности

- **Удалённый файловый менеджер (SFTP)** — просмотр папок, создание файлов и папок, переименование, удаление, скачивание (в т.ч. папок архивом `.tar.gz`), загрузка перетаскиванием.
- **Автодополнение пути** — при вводе в адресной строке выпадает список подпапок: клик/Enter — перейти, Tab — дописать путь, ↑/↓ — выбор, Esc — закрыть.
- **Поиск в текущей папке** — фильтрация по подстроке в имени без учёта регистра.
- **SSH-терминал** — встроенный терминал (xterm.js), вставка правой кнопкой мыши, настройка размера шрифта и буфера прокрутки.
- **Очередь передач** — загрузки и скачивания с прогрессом, паузой, повтором и отменой.
- **Просмотр и правка файлов во внешнем редакторе** — Блокнот, Notepad++ или VS Code, с контролем несохранённых изменений и предупреждением о правках на сервере.
- **Мониторинг VDS** — ОС, ядро, нагрузка, аптайм, использование CPU/RAM/дисков (кольцевые диаграммы).
- **Сессии** — сохранённые подключения (пароль или приватный ключ), быстрый реконнект при обрыве, проверка ключа сервера (известный/изменившийся).
- **Безопасность** — секреты хранятся отдельно от сессий в DPAPI-шифрованных файлах (`%APPDATA%/Termix`), содержимое ключа на диск не пишется.
- **Discord Rich Presence** — логотип Termix в профиле Discord во время работы.
- **Локализация** — русский и английский интерфейс.

Стек: **Tauri 2 + Rust (russh) + Svelte 5 + TypeScript + Vite 5**.
