# Автодополнение пути в адресной строке

Подсказки при вводе пути в файловом менеджере: выпадающий список подпапок,
в которые можно перейти.

## Поведение
- Ввод `/home/us` → список папок (`/home/user`, …).
- Слэш в конце (`/home/user/`) → все подпапки внутри.
- **Клик / Enter** — перейти в выбранную папку.
- **Tab** — только дописать путь (и показать следующий уровень), Enter — перейти.
- **↑/↓** — выбор пункта, **Esc** — закрыть.
- Переход из файлов (двойной клик, «Домой», кнопки) сам закрывает список.

## Реализация
- `src/components/FilesToolbar.svelte` — инпут, список, клавиатура, debounce 150мс,
  защита от гонок (счётчик запросов), максимум 8 пунктов, только папки,
  регистронезависимый фильтр по префиксу. Точное совпадение список прячет.
- `src/components/FilesPanel.svelte` — `navigateTo()` (установка пути + загрузка),
  передаётся в тулбар как `onNavigate`.
- Подсказки берутся живым `sftp_list` родительской папки; ошибки чтения молча
  прячут список, ручной ввод работает как раньше. Отдельных строк локализации нет.
