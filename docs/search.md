# Поиск в текущей папке

Фильтрация содержимого текущей удалённой папки (глобального поиска по серверу нет).

## Текущее поведение
- Обычный текст ищет по подстроке в имени, без учёта регистра.
- Пустой запрос показывает всё.
- Реализация: фильтр `visible` в `src/components/FilesPanel.svelte`,
  ввод — поле поиска в `src/components/FilesToolbar.svelte`.

## Маска `*.ext` (снята с реализации, спецификация сохранена)
- Бывшая логика: запрос вида `*.log` показывал все записи, чьё имя
  заканчивается на `.log` (без учёта регистра); работает и для составных
  расширений (`*.tar.gz`); одиночный `*` показывал всё.
- Бывший тултип поля (`files.searchHint`): «Маска *.log находит все файлы
  с этим расширением.» / «Mask *.log finds all files with that extension.»
- Если возвращать: восстановить фильтр по суффиксу в `visible`,
  ключ `files.searchHint` в `src/lib/lang/ru.ts` + `en.ts` (паритет обязателен)
  и `title` у инпута поиска.
